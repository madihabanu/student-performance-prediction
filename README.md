# Student Performance Prediction Using Machine Learning

## Project Overview
This project aims to analyse student academic data, identify patterns associated with academic performance, and predict student performance categories using Machine Learning techniques.

The system classifies students into two categories: **At-Risk** and **Not-at-Risk**, based on a defined final-grade threshold. Final and previous grades will be excluded from model input features to avoid data leakage.

## Objectives
- Collect and preprocess student academic data.
- Perform Exploratory Data Analysis (EDA).
- Identify factors associated with student performance.
- Develop and compare Machine Learning classification models.
- Evaluate models using appropriate performance metrics.
- Create interactive dashboards using Microsoft Power BI.

## Technologies Used
- Python 3.11
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Microsoft Power BI
- Git and GitHub

## Dataset
UCI Student Performance Dataset

Source: https://archive.ics.uci.edu/dataset/320/student+performance

## Project Structure
- `dataset/` – Dataset files.
- `notebooks/` – Jupyter notebooks and experiments.
- `reports/` – Analysis reports and documentation.
- `models/` – Trained Machine Learning models.
